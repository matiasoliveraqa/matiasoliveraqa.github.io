04 · ENGINEERING DISCIPLINE

Quality Standards

The principles that ensure test suites deliver reliable signal rather than maintenance drag.

01 // RESILIENT SELECTORS

Semantic Locators Over Brittle Paths

Tests strictly target user-facing ARIA roles (`getByRole`, `getByLabel`, `getByTestId`), completely avoiding fragile CSS hierarchies and auto-generated classes that break across UI redesigns.

02 // DATA ISOLATION

Atomic Tests & Independent State

Every automated test scenario initializes its own deterministic test data or mocks. Tests never rely on side-effects or order of execution, enabling fearless parallel execution across runners.

03 // RELIABILITY PROTOCOL

Zero-Tolerance Flakiness Protocol

A flaky test is treated as a defect in test engineering. Non-deterministic runs are automatically quarantined, inspected with Playwright trace viewer recordings, and rewritten for stability.

04 // SHIFT-LEFT GATES

Automated Pull Request Blocking Gates

Quality gates run on every pull request. Broken assertions, latency threshold regressions, or contract schema mismatches block merging automatically before reaching staging.
